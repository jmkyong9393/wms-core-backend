# UBCI (Used Book Condition Index) 평가 기준 명세서 (버전 2.0.0.0)
[Confidential - 내부 보안 등급]

본 문서는 AI 비전 스캐너가 중고 도서의 훼손 상태를 정량적으로 평가하고 최종 등급(S, A, B, 반려)을 도출하기 위한 **UBCI 점수 산출 알고리즘 및 판독 명세**입니다.

## 1. 2D 감점 매트릭스 확장 (Defect Type × Severity & Morphology)
AI가 식별한 BBox 결함의 종류(Defect Type)와 면적 비중(Severity/Area)뿐만 아니라, **측면(Edge View)의 기하학적 단절 및 형태학적 변형(Morphology)**까지 교차 평가하여 감점하는 매트릭스를 적용합니다.

*   **Minor (경미)**: 표지 전체 면적 대비 결함 면적 5% 미만
*   **Moderate (보통)**: 결함 면적 5% ~ 15% 미만
*   **Severe (심각)**: 결함 면적 15% 이상

| 평가 항목 (분류) | 세부 결함(클래스) | Minor (<5%) | Moderate (5~15%) | Severe (≥15%) / 형태학 임계치 초과 |
| :--- | :--- | :---: | :---: | :---: |
| **표지 (Cover)** | 긁힘 / 스크래치 | -2점 | -5점 | -10점 |

## 2. 점수 산정 공식 (Score Formula)
최종 점수는 100점에서 각 결함별 차감 점수를 누적하여 빼는 방식입니다.

1. **면적 퍼센트(%) 합산 평가**: 같은 카테고리의 결함이 여러 개 발견될 경우, 모든 BBox의 면적(%)을 합산한 총 면적을 기준으로 심각도를 재평가하여 단일 감점합니다.
2. **텍스트 침범 가중치 (Text Overlap Penalty)**: 결함 BBox가 도서의 텍스트 영역을 가릴 경우, 감점 점수에 **1.5배의 가중치**를 곱합니다.

`UBCI Score = 100 - SUM(Deduction based on Accumulated Area/Morphology * Text Overlap Multiplier)`

## 3. 메타데이터 API & 내지(Pages) HITL 하이브리드 워크플로우
AI만으로 완벽한 면적/유실물 산출이 어려운 영역은 관리자(Admin)의 수동 개입 및 메타데이터 API 검증을 혼용합니다.

### ① 필수 부속물 유실 다이나믹 감점 (Missing Accessories)
*   알라딘/교보문고 API를 호출하여 도서 정보의 'CD', '부록' 플래그와 해당 부속물의 **중요도(Importance)**를 파악합니다.
*   작업자 App에 부속물 체크리스트 팝업이 노출되며, 'X(없음)' 체크 시 아래 다이나믹 패널티가 가동됩니다.
    *   **중요도 하 (단순 부록, 띠지)**: UBCI 점수 -10점 감점
    *   **중요도 상 (어학용 CD, 해설집)**: 매입가 자체를 30%~50% 차등 삭감 (재무적 패널티)

### ② 내지 훼손 및 낙장 (Missing/Damaged Pages)
*   **3장 촬영 트랙**: 앞면 1장, 뒷면 1장, 속지 펼침면 1장을 사용합니다. 속지는 Doodle 후보를 참고하되 GPT-4o가 원본 전체를 판독하고, GPT-4o-mini가 세 원본을 종합 검증합니다.
*   **자동 감점 범위**: 촬영된 한 펼침면에서 필기(`WRITING`), 형광펜(`HIGHLIGHTING`), 접힘(`PAGE_FOLD`)이 확정되면 여러 종류가 함께 있어도 `INNER_PAGE_DAMAGE` 한 건으로 묶어 **-10점을 한 번만** 적용합니다. 이는 실제 훼손 장수를 추정한 값이 아니라 현재 촬영 범위를 5장 이하 구간으로 처리하는 운영 규칙입니다.
*   **오탐 차단**: 인쇄된 본문·악보·도형·표·장식은 필기나 형광펜 결함으로 보지 않습니다.
*   **관리자 확인(HITL)**: 판독 불확실, 이미지 품질 불량, 낙장 의심, 바코드 훼손, 기타 자동 감점 규칙이 없는 결함은 자동 점수·등급을 확정하지 않고 관리자에게 전달합니다.
*   **추가 증거가 있는 확장 트랙**: 여러 내지 사진이나 작업자 확인으로 실제 훼손 장수가 확인된 경우 아래 수동 기준을 적용합니다.
    *   5장 이하 훼손: -10점
    *   10장 이하 훼손: -15점
    *   10장 초과 훼손 또는 **낙장(Missing Page)**: 점수 무관 **즉시 반려(REJECT)**

## 4. 등급(Grade) 매핑 기준 (Thresholds)
차감 후 남은 최종 UBCI 점수를 기준으로 등급을 매핑합니다.

### 🟢 S등급 (MINT)
- **UBCI 점수**: `95 ~ 100점`
- **조건**: 결함이 거의 없는 새 책 수준.

### 🟡 A등급 (EXCELLENT)
- **UBCI 점수**: `85 ~ 94점`
- **조건**: 경미한 표지 스크래치나 모서리 찍힘 존재.

### 🟠 B등급 (NORMAL)
- **UBCI 점수**: `65 ~ 84점`
- **조건**: 뚜렷한 사용감, 가벼운 변색, 구조 결함(-5), 5장 이하 밑줄 등 허용.

### 🔴 반려 / 폐기 (REJECT)
- **UBCI 점수**: `65점 미만` (또는 치명적 결함 발견 시 점수 무관 반려)
- **치명적 결함 조건**: 
  - 🚨 **액체 오염 (`WATER_DAMAGE`) 및 형태 휨 (`PAGE_WARPING`)**
  - 제본 완전 벌어짐, 낙장, 펜/형광펜 10장 초과
