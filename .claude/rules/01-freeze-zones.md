# 코드 프리즈 구역 상세 및 예외 처리 절차

## 프리즈 대상

1. **LangGraph 4-Agent 파이프라인 구조**
   - Vision → Policy → Critic → Report 4단계를 단일 에이전트/단일 프롬프트로 병합 금지.
   - 모델 배정 고정: Vision Agent = GPT-4o, 나머지 3개 Agent = GPT-4o-mini.
   - 근거: 비용 최적화 구조와 판정 단계별 감사 추적성 보존.

## 예외 처리 절차

1. 변경 필요 사유(실측 근거 포함)를 조장에게 서면(문서)으로 제출한다.
2. 조장의 명시적 승인("예외처리 해줄게" 등)을 받은 뒤에만 diff를 작성한다.
3. 승인 사실을 본 문서의 예외 승인 이력에 기록하고, 관련 계획 문서를 참조로 남긴다.
4. 코드 이동(파일 분할 등)은 로직 불변이 입증되면 구조 변경으로 보지 않는다.
